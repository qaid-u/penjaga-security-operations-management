# Custom usability questionnaire — Pending Data Collection

This is a project-specific questionnaire, **not SUS** and not a validated instrument. Do not convert its answers into a SUS score or use SUS grading benchmarks.

After each interface, participants rate each statement from 1 (strongly disagree) to 5 (strongly agree), with a separate Not Applicable option. Participation and individual questions are optional.

1. I could navigate the interface easily.
2. The displayed operational information was clear.
3. I could find the requested security post easily.
4. The interface's presentation helped me understand the information.
5. Location/status indicators were understandable.
6. The available viewing/navigation controls were easy to use.
7. The interface responded quickly enough for my tasks.
8. I was confident that I had located the requested information.
9. Overall, I was satisfied with this interface for these tasks.

For A, item 6 refers to its ordinary navigation controls; for B it includes the camera. Item 5 may be Not Applicable for controls not provided by A. This difference must be reported when comparing items.

Open-ended prompts: Which feature was most useful? Which interaction was most confusing? What would you change? Do not enter actual confidential security incidents, real guard identifiers or unnecessary personal information.

Use the separate empty questionnaire CSV. Leave Not Applicable/missing responses blank, distinguish them from low ratings, and report valid n for each item. Summarize per-item distributions/median and optionally mean; do not invent a validated aggregate score. Summarize free-text feedback by transparent themes using anonymous excerpts only with consent. No participant answers are prefilled.
