# Bangunan Dato' Muhamad Ibrahim Munsyi model reference

On 25 October 2026 the user confirmed that this building uses the same model as Bangunan Dato' Mohamad Salleh Perang. `model_reference.json` records that relationship and links to the existing editable Blender file, GLB and manifest under `../bdmsp/`.

The geometry is shared without duplicating files. The building name and future operational records remain separate. This reference does not infer interior layouts or security-post coordinates and does not change the application's building mappings.
